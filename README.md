# Анализ пользовательской активности и A/B-тестирования

Проект по продуктовой аналитике, состоящий из двух частей.

## Цели проекта

- Сравнить активность пользователей приложения «Яндекс Книги» в Москве и Санкт-Петербурге.
- Проверить гипотезу о различии среднего времени активности пользователей.
- Оценить результаты A/B-теста нового интерфейса интернет-магазина.
- Проверить, повлиял ли новый интерфейс на конверсию в покупку.

## Основные этапы

### Часть 1. Анализ активности пользователей

- загрузка и предобработка данных;
- проверка дубликатов и пропусков;
- сравнение пользователей из Москвы и Санкт-Петербурга;
- проведение одностороннего t-теста;
- интерпретация статистического результата.

Результат: статистически значимых доказательств того, что пользователи Санкт-Петербурга проводят больше времени в приложении, не обнаружено.

### Часть 2. Анализ A/B-теста

- проверка распределения пользователей по группам;
- анализ пересечений с другими тестами;
- фильтрация событий за первые 7 дней после регистрации;
- расчёт конверсии в покупку;
- проверка статистической значимости различий;
- подготовка рекомендаций по внедрению нового интерфейса.

По текущим расчётам прирост конверсии составил 1,73 процентного пункта. Результат статистически значим, однако целевой прирост в 3 процентных пункта не достигнут.
